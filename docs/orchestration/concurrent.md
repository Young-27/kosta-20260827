# 동시 오케스트레이션

관련 커맨드: [`/parallel-check`](../../.claude/commands/parallel-check.md)

## 흐름

```text
                 ┌─ tester ─┐
대상 ────────────┤          ├── 결과 통합
                 └ reviewer ┘
```

`tester`와 `reviewer`를 순서 없이 한 번에 실행한다. 두 작업 모두 동일한 대상을 독립적으로 읽고, 상대방의 결과가 없어도 시작할 수 있으므로 대기 시간을 줄일 수 있다.

- `tester`: `tests/`에 테스트를 만들고 `npm test`로 확인한다.
- `reviewer`: 대상을 `CLAUDE.md` 규약 기준으로 리뷰한다.

두 작업이 모두 끝나면 결과를 하나의 표로 모은다. 결과가 서로 모순되면 모순임을 명시하고, 어느 결과를 선택했는지 근거를 함께 작성한다.

## 사용 시점

테스트와 리뷰처럼 서로 의존하지 않는 검증 작업에 사용한다. 구현 결과를 다음 단계의 입력으로 넘겨야 하는 경우에는 [순차 오케스트레이션](./sequential.md)을 사용한다.
