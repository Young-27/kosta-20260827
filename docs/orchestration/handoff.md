# 핸드오프 오케스트레이션

관련 커맨드: [`/handoff`](../../.claude/commands/handoff.md)

## 흐름

```text
implementer → reviewer
       ▲          │
       └─ 높은 심각도 지적 ─┘
```

1. `implementer`에게 구현을 맡긴다.
2. `reviewer`에게 결과를 리뷰시킨다.
3. 리뷰에 심각도 `높음`인 지적이 하나라도 있으면 해당 지적을 붙여 `implementer`에게 되돌린다.
4. 높은 심각도의 지적이 없어질 때까지 구현과 리뷰를 반복한다.

## 제한

- 왕복은 최대 3회다.
- 3회 뒤에도 높은 심각도의 지적이 남으면 기준을 낮추지 않고 남은 지적을 사람에게 전달한다.
- 매 왕복마다 `왕복 N회차`를 보고한다.

## 사용 시점

이미 구현 방향이 정해져 있고, 리뷰의 높은 심각도 지적을 해결하는 품질 게이트가 필요할 때 사용한다. 요구사항 분석과 테스트까지 포함한 전체 흐름에는 [순차 오케스트레이션](./sequential.md)을 사용한다.
